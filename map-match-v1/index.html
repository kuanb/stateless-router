What this proves—and what it does not

The demo proves sparse browser reads and local candidate matching work against an ordinary Protomaps archive. It uses declared one-way direction, but does not reconstruct connectivity, obey turns, or guarantee legal travel. Edge endpoints are explicit but synthetic; trimming is visual cleanup, not inferred routing topology.
